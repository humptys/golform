# GolForm — 골프 자세 교정

프로나 잘 치는 사람의 스윙 영상을 **기준**으로 등록해 두고, 내 스윙 영상을 올리면 기준과 어디가 얼마나 다른지, 왜 문제이고 어떻게 고치는지 알려 주는 휴대폰용 웹앱입니다. 분석 기록이 쌓여 점수와 항목별 수치의 변화를 볼 수 있습니다.

## 동작 방식

1. 영상의 각 프레임에서 관절 위치를 추출합니다 (MediaPipe Pose Landmarker, 브라우저 안에서 실행).
2. 손의 궤적으로 어드레스 · 백스윙 탑 · 임팩트 · 피니시 구간을 찾습니다.
3. 구간별 자세에서 측정값(상체 각도, 머리·골반 이동, 팔 펴짐, 템포 등)을 계산합니다.
4. 기준 영상들의 측정값 평균·편차를 기준 프로파일로 삼아 내 값과 비교하고, 차이가 큰 항목부터 교정 방법을 보여 줍니다.

영상으로 신경망을 새로 학습시키는 방식이 아닙니다. 기준 영상을 추가할수록 기준 프로파일(평균과 허용 범위)이 정교해집니다.

영상은 서버로 전송되지 않습니다. 기록은 기기의 브라우저(IndexedDB)에 저장되며, 동기화를 설정하면 수치와 구간 이미지만 내 Supabase 프로젝트에 올라갑니다.

## 휴대폰에서 쓰기

빌드 과정이 없는 정적 사이트입니다. HTTPS로 호스팅하면 됩니다.

- **GitHub Pages**: 저장소 Settings → Pages → Branch를 선택하고 폴더는 `/ (root)` 로 지정한 뒤, 발급된 주소를 휴대폰 브라우저에서 엽니다.
- 브라우저 메뉴의 "홈 화면에 추가"로 설치하면 앱처럼 쓸 수 있고, 저장된 기록이 브라우저에 의해 자동 삭제될 가능성이 줄어듭니다.
- 처음 분석할 때 포즈 모델(약 9MB)을 내려받으므로 인터넷 연결이 필요합니다.
- 앱 파일은 열 때마다 최신인지 확인해 받습니다(`sw.js`). 새 버전을 올린 뒤에는 새로고침 한 번이면 반영되고, 화면 위쪽과 설정 탭의 버전 번호로 확인할 수 있습니다.

## 결과 화면

문제 하나마다 사진 한 장을 보여 줍니다. 사람 주변을 확대한 사진에 지금 자세(빨강·노랑), 목표(초록 점선), 옮길 방향(화살표)만 그리고, 그 옆에 "무엇이 문제인지 → 어떻게 할지"를 두 줄로 적습니다. 메모마다 참고 영상 검색 링크와 출처(TPI 스윙 특성 문서, 기준값이 나온 측정 데이터)가 붙고, 긴 설명과 수치는 「자세히」를 눌러야 펼쳐집니다.

머리 위치는 양 귀의 중점으로 재고(고개를 돌리는 것과 머리가 밀리는 것을 구분), 임팩트는 손이 어드레스 위치로 돌아온 순간으로 잡습니다.

## 정면 + 측면 + 샷 데이터 통합 분석

분석 화면에는 칸이 세 개 있습니다: ① 정면 영상, ② 측면(타깃 후방) 영상, ③ 샷 데이터. 같은 스윙을 두 방향에서 찍은 영상과 그 샷의 데이터를 넣고 「분석 시작」을 누르면 하나의 기록으로 묶어 진단합니다. 영상은 한쪽만 있어도 되고 샷 데이터는 선택입니다.

- 촬영 방향은 어느 칸에 넣었는지로 정합니다. 영상이 반대 방향에서 찍은 것처럼 보이면 결과에 경고를 띄웁니다.
- 결과 맨 위의 종합 진단은 두 영상의 지적을 "핵심 패턴"(체중이 뒤에 남음, 일어섬, 회전 부족 등)으로 묶어 먼저 고칠 것 세 가지를 고릅니다. 정면과 측면에서 함께 확인된 패턴, 이번 샷의 구질과 연결된 패턴을 앞세웁니다.
- 전체 점수는 정면과 측면 점수의 평균이며, 기록 탭에는 스윙 하나가 한 줄로 쌓입니다.

## 샷 데이터와 종합 진단 (GDR 등 론치 모니터)

샷 캡처를 올리거나 숫자를 직접 넣습니다. 없으면 영상만 분석하고, 나중에 결과 화면에서 추가할 수 있습니다.

- 캡처의 숫자는 기기 안에서 읽습니다. 좁은 글꼴에서 7과 소수점을 놓치지 않도록 칸마다 두 가지 방식으로 읽어 합치고, 두 결과가 달랐던 칸은 노란 테두리로 표시해 확인을 요청합니다.
- 결과 맨 위의 종합 진단은 샷의 특징(출발 방향, 휘는 방향, 발사각, 백스핀)마다 영상에서 찾은 관련 자세를 번호로 잇고, 그 자세가 왜 그런 공을 만드는지 한 줄로 설명합니다. 아래 사진 메모에도 "이번 샷: …"으로 표시됩니다.
- 자세와 구질의 연결은 흔히 함께 나타나는 조합에 근거한 추정입니다. 클럽 페이스와 그립은 볼 수 없으므로, 연결되는 자세가 없으면 그렇게 표시합니다.
- 기록 탭의 「샷 데이터 추이」에서 캐리, 볼 스피드, 발사각, 좌우거리, 방향 편차(캐리 대비 %) 등이 클럽별로 누적됩니다.

## 클럽 종류

드라이버 / 아이언 / 어프로치 / 퍼팅을 골라 분석하며, 기준값과 기록이 종류별로 따로 관리됩니다.

- 드라이버·아이언: 풀스윙 전체 항목. 드라이버는 스탠스, 어깨 기울기, 핸드 퍼스트 등의 기준이 다릅니다.
- 어프로치: 작은 스윙도 인식하며 머리·하체 고정, 핸드 퍼스트, 리듬(약 2:1) 위주로 봅니다.
- 퍼팅: 정면 영상만 지원합니다. 손의 좌우 움직임으로 스트로크를 찾아 머리·하체 고정과 리듬을 봅니다.

## 기준 프로파일 (선수별 기준)

**「정석 폼」(내장 기준)** 은 영상 등록 없이 바로 쓸 수 있습니다. 투어 프로를 3D 장비로 측정해 공개한 데이터(가슴·골반 회전량, 템포 등)와 골프 레슨에서 일반적으로 가르치는 자세를 측정 항목별 기준값과 허용 범위로 옮긴 것이며(`js/textbook.js`, 출처 포함), 미들 아이언 풀스윙 기준입니다.

**「로리 맥길로이」** 는 공개된 3D 측정값(어깨 회전 116°, 골반 회전 42°)을 반영하고 나머지 항목은 투어 기준을 씁니다. 영상을 등록하면 영상에서 잰 값이 대신 쓰입니다. 넬리 코다는 공개된 측정 수치를 찾지 못해 영상 등록이 필요합니다. 실제 영상으로 보정한 값이 아니므로 점수 자체보다 크게 벗어난 항목과 시간에 따른 변화를 보는 용도입니다.

그 밖의 프로파일은 영상을 등록해 직접 쌓습니다. 기준 영상은 프로파일 단위로 쌓입니다. "로리 맥길로이", "넬리 코다"가 기본으로 들어 있고 이름을 직접 만들 수도 있습니다. 분석할 때 어느 프로파일과 비교할지 고릅니다.

- 선수 영상은 앱에 포함되어 있지 않습니다. 영상 **파일**을 직접 준비해 등록해야 합니다(링크만으로는 분석할 수 없습니다).
- 고정 카메라, 전신, 스윙 1회, 20초 이내 영상만 쓸 수 있습니다. 화면이 움직이거나 장면이 바뀌는 중계 영상은 수치가 틀어집니다.
- 슬로모션 영상은 등록할 때 「슬로모션 영상」을 체크하면 템포만 기준에서 빠집니다.
- 한 프로파일에는 한 사람의 스윙만 넣으세요.

## 기기 간 동기화 설정

기준 프로파일과 분석 기록(수치·구간 이미지)을 여러 기기에서 같게 유지합니다. 영상 원본은 동기화하지 않고 촬영한 기기에만 남습니다. 무료 [Supabase](https://supabase.com) 프로젝트가 필요하며 한 번만 설정하면 됩니다.

1. Supabase에 가입하고 새 프로젝트를 만듭니다.
2. 대시보드의 **SQL Editor**에 [`supabase/schema.sql`](supabase/schema.sql) 내용을 붙여넣고 실행합니다.
3. **Project Settings → API**에서 `Project URL`과 `anon public` 키를 복사합니다.
4. 둘 중 하나를 합니다.
   - [`js/config.js`](js/config.js)에 두 값을 적어 커밋합니다. 모든 기기에서 따로 입력할 필요가 없어집니다.
   - 또는 각 기기에서 앱의 「설정」 화면에 두 값을 입력합니다.
5. 앱의 「설정」에서 이메일과 비밀번호로 가입합니다. 확인 메일이 오면 링크를 누른 뒤 로그인합니다.
   - 확인 메일의 링크가 열리지 않는 주소로 연결되면 Supabase의 **Authentication → URL Configuration → Site URL**을 앱 주소로 바꾸세요. 혼자 쓰는 앱이라면 **Authentication → Providers → Email**에서 "Confirm email"을 꺼도 됩니다.
6. 다른 기기에서는 같은 계정으로 로그인만 하면 기록이 내려옵니다.

`anon` 키는 브라우저에 공개되도록 설계된 키이고, 데이터는 `schema.sql`의 행 수준 보안 정책(로그인한 본인 행만 접근)으로 보호됩니다. `service_role` 키는 절대 넣지 마세요.

같은 기록이 두 기기에서 다르게 바뀐 경우 더 최근에 수정된 쪽이 남습니다. 한 기기에서 지운 기록은 다른 기기에서도 지워집니다.

## 참고 영상 링크

지적 항목마다 교정 레슨과 기준 선수의 스윙을 찾는 유튜브 검색 링크가 붙습니다. 특정 영상 주소는 사라지거나 바뀌기 때문에 검색 결과로 연결합니다.

## 로컬 실행과 테스트

```
python3 -m http.server 8000   # http://localhost:8000
npm test                      # 구간 검출·측정·비교·동기화 규칙 단위 테스트
```

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/pose.js` | 영상 → 프레임별 관절 좌표 |
| `js/swing.js` | 구간 검출, 측정값 계산 (순수 로직) |
| `js/metrics.js` | 측정 항목 정의와 교정 문구 |
| `js/profile.js` | 기준 프로파일 생성, 비교·점수 |
| `js/textbook.js` | 내장 기준 「정석 폼」의 기준값 |
| `js/annotate.js` | 구간 사진 위에 골격과 교정 표시 그리기 |
| `js/patterns.js` | 정면·측면의 지적을 핵심 패턴으로 묶기 |
| `js/shot.js` | 샷 데이터 해석(구질 판정, 자세와의 연결) |
| `js/ocr.js` | 캡처 화면에서 숫자 읽기 |
| `js/sources.js` | 지적 항목별 출처(결함 설명 자료, 기준 데이터) |
| `js/links.js` | 지적 항목별 참고 영상 검색 링크 |
| `js/db.js` | 기기 내 저장, 백업 |
| `js/reconcile.js` | 기기와 서버의 기록을 맞추는 규칙 (순수 로직) |
| `js/sync.js` | Supabase 로그인과 동기화 |
| `supabase/schema.sql` | 동기화용 테이블과 보안 정책 |
| `js/app.js` | 화면 |

## 한계

- 클럽 페이스, 그립, 클럽 궤도, 구질은 측정하지 않습니다. 몸의 관절 위치만 봅니다.
- 카메라 한 대의 2D 영상이라 회전량은 추정치이고, 가려진 쪽 팔다리는 오차가 큽니다.
- 기준 영상과 내 영상의 촬영 방향(정면 / 타깃 후방)이 같아야 합니다.
- 점수는 "기준과 얼마나 비슷한가"이며 스윙의 절대적인 평가가 아닙니다.
